# 🔐 Password_Cracking

## 📌 About This Repository

This repository is created for educational purposes and cybersecurity learning. It focuses on understanding password security, password hashing, and authorized password auditing using different security tools.

## 🛠️ Tools Used

In this repository, we use two modules:

### 1. John the Ripper
- Password security auditing tool.
- Supports multiple password hash formats.
- Helps understand password strength and hash security.
- Useful for authorized password auditing.


### 2. NetworkWalks Password Cracker & Hash Cracker
- Used for learning about password and hash analysis.
- Helps understand password security concepts.
- Included for educational and authorized security testing.
